Plot a trend

This layer is one row per well/POD, not repeated measurements — so for each attribute you check, this averages that value across all sites inside the drawn filter, by year, and plots it as its own trend line (e.g. "has average well depth here gotten deeper over the decades?"). It's not a per-site history over time.

Animate through time

What this shows: as the year advances, only PODs whose completion date falls within the current window are drawn on the map — everything else is hidden, the same way the Filters-tab date range hides points, just moving automatically. How to use it: set the date range below (or on the Filters tab — they're the same range), pick a step size and a mode, then press Play, or use Back/Forward to move one step at a time. Narrowing by status, use, or a drawn/place area first (Filters panel, left) animates that specific slice of history instead of everything.

Cumulative: shows every POD completed from the start of the range up through the current year — the set only grows. Single bin only: shows just the PODs completed within the current step's window (e.g. one 5-year slice) — older PODs disappear again as the window moves forward, so you're always looking at one period at a time rather than the running total.
